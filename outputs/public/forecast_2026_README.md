# forecast_2026_* の説明

**注意: 段3で、モデルは前年値に勝てなかった(主の集計・2020〜2024年。改善率の95%区間が0をまたぐ)。この予測は参考値で、精度は2027年の答え合わせまで未検証。**

| ファイル | 内容 |
|---|---|
| `forecast_2026_predictions.csv` | 2026年の転入超過率(‰)の予測。scope = main(主の集計、1,739市区町村)/ sensitivity(避難指示区域の候補を除いた別枠、1,728)。`pred_*` = 点予測、`lo_*`・`hi_*` = 95%区間(規模の階級ごとの過去の絶対誤差の95%点)。`y_2025_permille` = 2025年の実績(住民基本台帳人口移動報告 2025年結果から計算) |
| `forecast_2026_backtest_2020_2025.csv` | 過去の評価年のMAE。2020〜2024年は段3の表と一致。**2025年は参考値で、勝敗の判定に使わない**(`docs/段4_前向き予測_設計_追記1.md`) |
| `forecast_2026_interval_widths.csv` | 区間の半幅(‰)。手法 × 規模の階級 |
| `forecast_2026_hyperparams.csv` | 2026年の予測に使った設定値(時間順の検証で選んだ) |

- 固定の記録: `ledger/forecast_2026_manifest.csv`(SHA256・コードのコミット)、`ledger/forecast_2026_addenda.csv`(設計の追記)。**予測の表は、固定後に変更していない**。表そのものに注意書きを入れると、固定したSHA256が変わるため、説明はこのファイルに置いた。
- 勝敗の判定の基準: `docs/段4_前向き予測_設計.md` §5 と `docs/段4_前向き予測_設計_追記1.md` §2。
- 答え合わせは、2026年結果の公表後(2027年4月ごろの見込み。未確認)。答え合わせのコードは未実装。
- 出典: 独立行政法人 統計センター SSDSE-A を加工して作成。総務省統計局「住民基本台帳人口移動報告」(2025年結果)を加工して作成。
