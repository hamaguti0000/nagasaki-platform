## 2. 答え合わせの判定(固定)
| 問い | 固定した内容 |
|---|---|
| 何を | 2026年の転入超過率(‰)。日本人移動者・国内移動。分母は2020年国勢調査の日本人人口(段3と同じ定義)。対象は、主の集計の除外規則に合う市区町村のうち、2026年結果の表(住民基本台帳人口移動報告 年報 2026年、表11-1・11-2に相当する表)と予測表の両方にあるもの |
| どの指標で | 判定の指標は **MAE(‰)の改善率** = 1 − MAE(手法)/MAE(基準)。人口加重MAE・符号一致率・区間の被覆率は、報告のみ(判定に使わない) |
| 何と比べて | 基準は **B0(前年値)** と **B1(直近3年の平均)**。判定の対象の手法は **M1(Ridge)** と **M2(勾配ブースティング)** |
| 区間 | 市区町村をまとまりとした再標本化、2,000回、seed = 20261013、95%区間(段3の `cluster_bootstrap` と同じ方法) |
| 勝ち | 手法Mの改善率の95%区間の**下限が0より大きい**ことが、B0とB1の**両方**に対して成り立つとき、「Mは勝った」 |
| 部分的な勝ち | B0に対してのみ下限が0より大きく、B1には0をまたぐ(または負)とき、「B0にのみ勝った。B1には勝てなかった」と書く。「勝った」とは書かない |
| 負け | 区間の**上限が0より小さい**とき、「基準のほうが良かった」と書く(B0・B1のそれぞれについて) |
| 判定不能 | 区間が0をまたぐとき、「勝てなかった(差は言い切れない)」 |
| 複数の比較 | 2手法 × 2基準 = 4つの比較。**多重性の補正はしない**。4つ全てを報告する |
| 長崎 | 21市町は**補助**。同じ指標と区間を報告するが、勝敗の判定には使わない(評価点が少ない。21点) |
| 感度分析 | 避難指示区域の候補を除いた集合。別枠で報告し、判定に使わない。主の集計と混ぜない |
| 区間の被覆率 | 予測表の95%区間に、実績が入った割合を、手法・規模の階級別に報告。90%未満または98%超は「較正に問題がある」と書く。原因は「検証していない仮説」 |
| 毎回付ける文言 | 「評価は2026年の1年のみ。1年の結果では、手法の優劣は決められない」 |

## 3. 2025年のバックテストの位置づけ
**参考値であり、勝敗の判定には使わない。** 区間の幅(規模の階級ごとの絶対誤差の95%点)を作るために加えた評価年で、2026年の判定とは別である。

| 参考: 2025年(主の集計、1,739市区町村、2024年までで学習) | MAE(‰) | 改善率 vs B0 [95%区間] | 改善率 vs B1 [95%区間] |
|---|---|---|---|
| B0 前年値 | 3.79 | — | — |
| B1 3年平均 | 3.14 | +17.3% [+13.2%, +20.9%] | — |
| M1 Ridge | 3.08 | +18.7% [+15.3%, +22.0%] | +1.7% [−0.6%, +3.9%] |
| M2 勾配ブースティング | 2.98 | +21.3% [+17.5%, +24.8%] | +4.9% [+2.6%, +7.0%] |

(上の区間は、この追記のために、事後に計算した。市区町村をまとまりとした再標本化。判定には使わない。)

**段3の結論との関係(矛盾しない)**
- 段3の結論は、「2020〜2024年の5年をまとめた主の集計では、モデルはB0に勝てなかった(Ridge [−7.5%, +10.7%]、勾配ブースティング [−14.6%, +13.9%]。区間が0をまたぐ)」。これは変わらない。
- 年ごとには、順位が入れ替わる。2021年は、B1と両モデルがB0より悪く、2022年は、B1と勾配ブースティングがB0より悪かった(Ridgeは良い)。2023年・2024年は、全てB0より良い(Ridge +14.1%・+10.4%、勾配ブースティング +15.0%・+14.3%。`outputs/public/panel_model_by_year.csv`)。2025年は、2023年・2024年と同じ側にある。
- 2025年の良い結果は、**1年の結果**で、将来も続くことを示さない。また、2025年は**B1もB0に勝っている**ため、「モデルが良い」というより「前年値が不利な年だった」可能性がある(検証していない)。
- 段3の結論を、2025年の結果で書き換えない。
