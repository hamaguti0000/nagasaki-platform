# 作品1: データの落とし穴 — 県の観光客延べ数の「再算定」と、比べ方で変わる伸び率

作成日 2026-10-14。**県の統計(長崎県観光統計)を使うため、元の表の値は載せません**(県の著作権の条項との関係は、README「含めていないデータ」)。載せるのは、2つの伸び率と、その出典の位置のみ。区分: 「実測」= 取得した表で確認した値、「計算」= 実測値からの算術、「未確認」。

## 1. 何が起きているか
長崎県は、算定方法を市町ごと・時期ごとに見直し、**前の年の値を新しい方法で再算定**します。このため、異なる年版の表から値をそのまま拾って比べると、「見直しの前の値」と「見直しの後の値」を比べてしまうことがあります。

長崎市の観光客延べ数(2022年 → 2025年)の例:

| 比べ方 | 伸び率 | 内容 |
|---|---|---|
| 公表値をそのまま比べる | **+55.9%** | 2022年の値と2025年の値の比(2024年版で行われた、2023年の値の再算定=算定方法の見直しを、またぐ) |
| 各年版の「前年比」だけをつなぐ | **+43.2%** | 2023年版(+25.9%)× 2024年版(+7.2%)× 2025年版(+6.1%)。各年版は、同じ算定方法の前年と当年の比 |

差は約12.7ポイント。**差の主因は、算定方法の見直し**(長崎市。2024年版の本文が、2023年の値を再算定した旨を記載。`ledger/revision_notes.csv` の「2024年版・対象年2023・長崎市・`method_change`」の行)と読めます(因果の検証は未実施)。

## 2. 出典(県の資料の表と行)
| 数字 | 出典 | 位置 |
|---|---|---|
| +55.9% | 長崎県観光統計 集約表(県サイトのExcel。URL・SHA256は `config/sources.csv` の `kanko_agg_visitors`) | シート「観光客延べ数」、14行目(長崎市)の P列(2022年)と S列(2025年)の比。計算: 1.559 |
| +25.9% | 長崎県観光統計 令和5年(2023年)版 本文(`kanko_honbun_2023`) | 「(参考)令和5年市町別観光客数」の表の、長崎市の行の「前年比」 |
| +7.2% | 同 令和6年(2024年)版 本文(`kanko_honbun_2024`) | 「(参考)令和6年市町別観光客数」の表の、長崎市の行の「前年比」 |
| +6.1% | 同 令和7年(2025年)版 本文(`kanko_honbun_2025`) | 「(参考)令和7年市町別観光客数」の表の、長崎市の行の「前年比」 |
| +43.2% | 上の3つの積 | 計算: 1.259 × 1.072 × 1.061 = 1.432(各年版の前年比は、小数第1位までの公表値) |

- 3つの本文の表は、各年版の本文の9ページ目の後に位置する(ページ番号の記載は**未確認**。PDFのテキスト抽出で、行を確認)。
- 各年版の「前年比」の列と、集約表の値から作った比は、同じになる(2023年版の値 → 2024年版の値 → 2025年版の値。計算で確認)。
- 公表の元の値(人数)は、**載せません**。再現は、`make fetch` で県のサイトから取得して行います(取得物は `.gitignore` で除外)。

## 3. 限界
- 長崎市1市の例です。他の市町の再算定の影響は、`ledger/comparability_flags.csv` の比較不可フラグを参照(観光客延べ数のみ)。
- 「+43.2%」は、各年版の前年比を、単純につないだ値です。年版ごとの算定の基準が違うことは、この値自体に含まれます。**正しい伸びの値と主張するものではありません**。「公表値を直接比べると、約13ポイント違って見える」という、比べ方の注意が、この作品の主旨です。
- 県の算定方法の見直しの理由(宿泊税申告実績・人流データサービスの活用など)は、本文の注記の要約(`ledger/revision_notes.csv`)による。見直しの妥当性は、評価していません。
