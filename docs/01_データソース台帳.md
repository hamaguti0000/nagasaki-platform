## 凡例と調べ方

- **未検証**: 実行して確かめていないもの(取得スクリプトの動作、実データの行数など)。
- 「利用条件」の「原文」は提供元ページの文言の引用。「私の解釈」は私の読みで、法的な判断ではない。
- 規模は「実際に確認できた分のみ」を書く。ほかは「未確認」。
- 更新頻度は、提供元ページで確認できたものだけを書く。

## 1. e-Stat API
- **提供元・取得**: 総務省統計局。ユーザー登録後、マイページでアプリケーションIDを発行して利用する(検索結果の記載。公式FAQの要約)。
- **形式・API**: 仕様書 Ver3.0(令和元年7月公開)。機能は、統計表情報取得、メタ情報取得、統計データ取得、データセット登録・参照、データカタログ情報取得、統計データ一括取得(検索結果の記載)。
- **更新頻度**: 統計表ごと(未確認)。
- **規模**: 未確認(appId未発行のため、実際の取得は行っていない=未検証)。
- **利用条件(原文)**: 「複製、公衆送信、翻訳・変形等の翻案等、自由に利用できます。商用利用も可能です。」「コンテンツを利用する際は出典を記載してください。」「コンテンツを編集・加工等して利用する場合は、上記出典とは別に、編集・加工等を行ったことを記載してください。」「編集・加工した情報を、あたかも国(又は府省等)が作成したかのような態様で公表・利用してはいけません。」「外部データベース等とのＡＰＩ連携等により取得しているコンテンツについては、その提供元の利用条件に従ってください。」(e-Stat 利用規約ページ)
- **私の解釈**: 出典と加工の明記をすれば、GitHub公開・受託の双方で使えそう。ただし統計表ごとに別の利用ルールが付く場合(「別紙」)があるため、使う表ごとに確認する。API利用時のクレジット表示は、FAQの記載(検索結果の要約)による。
- **長崎での使いどころ**: 国勢調査・経済センサス・賃金構造などの市町別の時系列。市町別の人口・事業所数を、観光指標の「分母」にする。
