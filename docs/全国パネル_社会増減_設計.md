## 1. 題材と問い
- **目的変数**: 市区町村の**転入超過率**(人口1,000人あたり) = (転入者数 − 転出者数) ÷ 期首の人口 × 1,000。国内移動(市区町村間移動)のみ。
  - 統計局の「社会増減数」は国外との移動を含む定義(原文: 「社会増減数＝（転入者数－転出者数）＋（国外からの転入者数－国外への転出者数）＋移動前の住所地不詳 －職権消除等」)。本書の目的変数は国内移動のみで、**「社会増減」そのものではない**ことを明記する。
- **問い**: (a) 転入超過率と、所得・住宅着工・子育て世代の規模・人口規模などの**関連**はどうか(要因の整理)。(b) 前年までの情報で、翌年の転入超過率をどこまで当てられるか(1年先の予測)。(c) 全国で学習したモデルは、長崎の21市町で、簡単な基準より良いか。
- **単位**: 市区町村 × 年(暦年)。

## 5. 予測の設計
### 5.1 特徴量(前年までに得られるもののみ)
- 目的変数のラグ(t, t−1, t−2)、人口規模(対数)、人口密度(人口÷可住地面積)、外国人比率、年齢構成(直近の国勢調査。時点が古い旨を付ける)、課税対象所得(1人あたり)とその変化、着工新設住宅戸数(人口あたり)、児童数の変化、大都市圏への所属(定義の根拠を明記)。
- 都道府県の固定効果は、「都道府県ごとに外す検証」と整合しないため、標準では使わない。

### 5.2 基準手法(**先に固定する**。結果を見てから変えない)
| # | 基準 | 内容 |
|---|---|---|
| B0 | 前年値 | y(t+1) の予測 = y(t) |
| B1 | 直近3年平均 | y(t), y(t−1), y(t−2) の平均 |
| B2 | 規模階級の平均 | 人口規模の階級別の、全国の前年の平均(縮約) |
| B3 | 全国一定 | 全国の前年の平均(転入超過率の中央値) |

### 5.3 モデル候補
| # | モデル | 目的 |
|---|---|---|
| M1 | 正則化線形回帰(Ridge/Elastic Net) | 解釈と、強い基準 |
| M2 | 勾配ブースティング(乱数のseedを固定) | 非線形・交互作用 |
| M3 | 階層(混合効果)モデル(市区町村規模・都道府県のランダム効果) | 小規模自治体の縮約。サンプルが小さい長崎向けに部分プーリング |
- 予測区間: 分位点回帰または適合的予測(コンフォーマル)。被覆率を検証する。
- 小規模自治体(人口が小さい)は、人数が少なく率が大きく振れる。**縮約(M3)と、人口加重の指標を併記する**。

### 5.4 評価方法(過去で試す検証)
| 検証 | 内容 | 何が分かるか |
|---|---|---|
| (a) 時間で切る | 学習: 〜T年、評価: T+1年。T+1 = 2020, 2021, 2022, 2023, 2024 の5分割(拡張窓)。ハイパーパラメータは学習期間内の時間分割CVのみで決める | 将来の年への当てはまり。2020〜2021年(感染症による移動の変化)は**別に報告**する |
| (b) 都道府県ごとに外す | 47分割。評価する都道府県の全市区町村を学習から外す | 学習していない地域への当てはまり |
| (c) (a)と(b)の組み合わせ(**本題**) | 長崎を学習から外し、かつ、評価年より前の年のデータだけで学習する。長崎の21市町を評価する | 「全国で学習して長崎に当てはめる」の検証 |
- 時空間の漏れの防止: 同じ年の他県のデータを学習に使うと、同年のショック(感染症・災害)を共有する。(c)では、**評価年より前の年のデータのみ**を使う。
- 評価の件数: 長崎 21市町 × 5年 = **105点**(計算)。うち、人口1万人未満の市町は2(令和2年国勢調査、実測)、3万人未満は12。

### 5.5 評価指標
| 指標 | 目的 |
|---|---|
| MAE(人口1,000人あたり、‰の差) | 基本の誤差 |
| 人口加重MAE | 小規模自治体の振れの影響を抑える |
| 基準B0に対するMASE、改善率(1 − MAE_model / MAE_B0) | 簡単な基準に勝っているか |
| 符号の一致率(転入超過か転出超過か) | 実務上の使い方 |
| 順位相関(Spearman。同じ年の市区町村間) | 相対的な位置の再現 |
| 区間の被覆率と幅 | 不確かさの妥当性 |

### 5.6 長崎の21市町の結果の見せ方
- 21点は少ない。**統計的な有意差を、市町間・手法間で主張しない**。
- 見せるもの: (1) 全国の誤差の分布の中で、長崎の誤差がどこにあるか(パーセンタイル)。(2) 21市町を個別に、予測と実績を並べた図(区間つき)。(3) 21市町の平均誤差の不確かさ(市町をまとまりとした再標本化による区間)。(4) 小規模町の注記(人数が少ないため率が振れる)。
- 全国での結果(評価点が多い)を主たる根拠とし、長崎は「当てはめの確認」と位置づける。

### 5.7 勝てなかった場合の方針(事前に固定)
- モデルが基準B0・B1に対して、改善率の区間が0を含む場合は、「**勝てなかった**」と明記し、基準手法を採用として報告する。成果は「予測が難しいこと、どの要因が弱い関連を持つか」とする。
- 全国で勝ち、長崎で勝てない場合は、そのまま報告し、考えられる理由(離島・小規模・産業構造)を、**検証していない仮説**として書く。
- モデルの選択に、評価期間(2020〜2024年)の結果を使わない。評価の再利用(結果を見てからの変更)はしない。変更した場合は、変更の理由と、変更前の結果を併記する。

## 6. できないこと・言えないこと
- **因果の断定**: 所得・住宅着工と転入超過の関連は観察データの関連で、因果ではない(逆の因果、共通の原因がありうる)。
- **個人の行動**: 市区町村の集計値からは、個人の転居の理由は分からない(生態学的誤謬)。
- **ショックの予測**: 災害、政策、大規模開発、感染症の変化の予測はできない。
- **長期の予測**: 1年先のみを対象とする。5年先などの推計は、社人研の推計(別の枠)の役割。
- **月次・季節**: 年次のみ。3〜4月への移動の集中などは扱えない。
- **外国人・国外との移動**: 目的変数は日本人移動者の国内移動。
- **長崎21市町での結論**: 21点では、市町間の優劣・ランキングは確定できない。
- **最新年**: 住民基本台帳人口移動報告の2025年結果(市区町村別)は公表済みだが、D1の掲載年次は2024年まで(実測)。2025年は評価に使えない(D2から直接取得する場合は別)。
