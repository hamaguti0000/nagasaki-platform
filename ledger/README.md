## revision_notes.csv の作り方と限界
- 作成: 別フォルダー(nagasaki_kanko_v2)の台帳の「再算定・注記」シートを**読み取り**、2015〜2025年版について、区分・市町・要約・観光客延べ数の変化を転記・要約した(ファイルのコピーではない)。「(参考)修学旅行宿泊者数」と「(なし)」は対象外。
- 原本との照合(`make validate` の V53): 注記の市町名が、県の本文PDFの「再算定」「算定方法の見直し」「訂正」の近くにあるかを機械で確認している。2015年版のPDFは文字を取り出せず**未検証**。
- 区分: `method_change`(算定方法の見直し)、`correction`(公表数値の訂正)、`correction_unnamed`(市町名の記載なし)、`listed_no_reason`(再算定対象として列挙。理由の記載なし。観光消費額側)、`scope_note`(全体の注意書き)。
- 比較不可フラグの規則: N年版で市町の算定方法が見直された場合、見直し後の基準は(N-1)年の再算定値から始まる。よって、(N-2)年と(N-1)年の間を境界とする。県は「再算定は前年に限る」としているため、さらに前の年は旧基準のまま。
- 限界: 理由の記載がない再算定(`listed_no_reason`)は、観光客延べ数のフラグには使っていない(観光消費額の側のため)。

## 検証が注記と整合することの意味(V50〜V52)
- V50: 集約表で県が朱書き(再算定後)にした観光客延べ数のセル(2014〜2024年)は、全て注記に対応する。
- V51: 注記が「観光客延べ数が変化した(≠0)」と記録した市町・年は、集約表で朱書きになっている。
- V52: 比較不可フラグの「見直し後の年」は、朱書きのセルに一致する(変化0の注記を除く)。
- 逆(注記があるのに朱書きがない)は要求していない。注記には観光消費額のみの再算定が含まれるため。
